EMPLOYEE ATTENDANCE & LEAVE MANAGEMENT SYSTEM
Pure HTML, CSS and JavaScript version.

HOW TO RUN:
1. Extract this ZIP file.
2. Open the folder.
3. Double-click index.html (or open it with Chrome/Firefox).
4. No Node.js, React, TypeScript, Vite or installation is required.

FILES:
- index.html: page structure (HTML)
- style.css: design and responsive layout (CSS)
- script.js: navigation, employee records, attendance, leave requests, reports and browser storage (JavaScript)

DATA:
Records are saved in this browser using localStorage. Use Settings > Export data to download a JSON backup.
This is a front-end demonstration project. It does not include a server/database or multi-user login.
